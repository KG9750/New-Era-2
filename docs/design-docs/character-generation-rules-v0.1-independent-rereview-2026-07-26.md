## 4. 与上位设计和 Gate 1 的一致性

当前三个快照在以下边界上一致：

- 玩家聚落开局 4 人，永久人口上限 10；
- 每个约两月阶段最多一次标准永久加入机会；
- 紧急补员不创造净增长；
- 单个 NPC 聚落永久人口上限 15；
- Gate 1 只使用林禾、乔磐、苏霁、陈渡 4 名固定测试人物；
- Gate 1 不实现完整 MBTI、复杂关系、NPC 聚落、人口增长或运行时人物生成器；
- 乔磐的加班红线在触发前可见，触发后不随机扩张为无关抗命；
- 当前两周切片仍属于 §20 阶段 A0，不是 50 人内容制作阶段。

外部一致性复核结论为 `CONSISTENCY_PASS`，未发现 P0 或 P1 冲突。

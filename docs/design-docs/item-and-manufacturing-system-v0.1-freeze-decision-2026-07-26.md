## 1. 冻结范围

本决议冻结《物品与制造系统设计 V0.1》R1 中已经标记为“继承基线”或“R1 冻结基线”的设计职责，包括：

- 物品分类、形态与标签体系；
- 批量物资、独立物品、设施资产、生长实体和权利记录的边界；
- 库存分配状态与承诺生命周期；
- 生存、工业、安全、政治四条资源主链；
- 制造、维修、拆解和品质输入职责；
- 人物与关键物品的单一权威关系；
- 阶段化接入、候选内容与大规模数据制作边界。

## 3. 实现边界

本次冻结不改变当前 Gate：

- Gate 1 仍只允许一个化肥物品样本；
- 不实现通用库存、制造、维修、装备、武器、战斗或伙伴动物运行时；
- 不制作或导入约 220 项候选内容；
- 不解锁 Gate 2–4；
- 不把设计复审通过表述为玩家测试通过。

## 4. 后续接入顺序

1. Gate 1 先验证两周经营闭环；
2. 化肥在 Gate 1 中验证有限库存、计划条件、预测变化和偏差解释；

4. 后续 Gate 的新证据若要求修改本基线，以新版本替代，不回写伪装成 R1 原始结论。

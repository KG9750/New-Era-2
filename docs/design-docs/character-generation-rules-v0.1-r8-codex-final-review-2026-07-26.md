## 最终核验范围

- 玩家开局 4 人、永久人口上限 10 人、NPC 聚落上限 15 人；
- 标准十二个月六个固定两月阶段与每阶段最多一次标准加入机会；
- 迟到返回、跨阶段补员席位、候选拒绝、三周期耗尽和配置/因果阻断；
- 六维链保护集与七维同席位质量比较；
- 完备损失因果、撤销/替代/恢复语义和玩家因果反刷；
- `ExternalPersonStub` 自包含补全上下文；
- 不可变关系基线、完整事件流和版本化纯 reducer；
- 四级固定种子派生链及已知答案向量；
- `PartyValidation` 动作注册表、资格、红线、替代动作和单点失效；
- Gate 1 乔磐红线动作、阈值与替代动作字段。

## 终审压力测试

- 历史签名 A → 不可比 B → 支配 A 的 C：C 被保护集阻断；
- 旧处决 → 撤销 → 恢复永久身份 → 后来疾病死亡：旧动作从有效因果集合排除，结果唯一为 `external_uncontrolled`；
- 恢复后重新签发：必须使用新动作 ID，新旧动作不会混用；
- pending 候选的拒绝、驱逐、死亡、被俘和永久失效：统一进入 14 日冷却，不创建人口席位；
- seed KAT：四级结果逐项一致；
- 月 3 首 tick 多个人口事件：rollover 后按稳定总序重放；
- 非标准日历的空档、重叠、重复 ID 和首尾缺失：阻止初始化。

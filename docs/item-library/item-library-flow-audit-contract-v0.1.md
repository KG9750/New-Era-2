# 候选物品库 R2-B 制造流、循环与候选经济审计合同 V0.1

**项目：** Project-004-New Era 2  
**上游基线：** `new-era-2.item-library.r1-c7-candidate`  
**上游审计：** `R2A_REVIEW_PASS`  
**内容状态：** `candidate_only`  
**运行时授权：** 无  
**适用范围：** 196 个库存物品、90 个工艺，以及工艺使用的设施、工具、岗位与四条资源主链

## 1. 目的

R2-B 在不修改 R1 物品、工艺、产量、耗时或 `base_value` 的前提下回答：

1. 每个制造输入是否能追溯到生产或外部获得来源；
2. 每个制造产出是否具有后续工艺用途或明确的使用、安装、消耗、损坏、交付等终端去向；
3. 制作—拆解循环是否具有正时间成本和有损回收边界，避免无损复制；
4. 哪些材料、设施、工具和岗位同时服务多条资源主链，构成候选共享瓶颈；
5. 哪些候选价值关系明显偏离同批工艺，需要在未来选择进入运行时前校准。

本审计是候选内容风险筛查，不是价格、产能、市场、技能曲线或正式平衡结论。

## 3. 制造流口径

### 3.1 上游来源

一个库存物品满足以下任一条件即具有候选上游来源：

- 至少一个工艺把它列为主产出或库存副产物；
- 至少一条 `acquisition_paths` 不是 `manufacture`，例如农业、采集、回收、贸易、任务或行政分配。

没有工艺生产者、又只有 `manufacture` 获得路径的物品属于断裂来源。

审计还要从所有非 `manufacture` 获得路径出发，沿转化图计算可达集合。任何已消耗工艺输入或拆解目标若只存在于没有外部起点的封闭循环，同样属于断裂来源。

可达性按工艺超边计算，不能把多输入工艺拆成“任一输入可达即可产出”：

- 每个直接输入形成一个必需输入位；
- 某输入位若有替代规则，则主输入或任一允许替代项可满足该输入位；
- 所有输入位，以及维修/拆解的目标实例，都可达时，工艺才可执行；
- 普通工艺和拆解工艺执行后才把库存产出加入可达集合；维修不创造新的目标实例。

### 3.2 终端去向

工艺产出满足以下任一条件即具有候选终端去向：

- 被其他工艺作为输入或替代输入；
- 具有不属于 `reserve`、`trade`、`deliver`、`store`、`inspect` 的实际动作；
- 具有消耗、安装、损坏、腐坏、交付、查扣、丢失或拆解等流失路径。

本审计不要求所有终端物品继续进入另一条工艺；食品、装备、家具、药品与文化物品可以直接结束制造链。

### 3.3 转化图

有向转化边按以下规则建立：

- 普通工艺：已消耗直接输入及其允许的替代输入指向主产出和库存副产物；
- 拆解工艺：被消耗的目标实例指向回收产出；
- 维修工艺不创造新目标实例，不进入转化循环图；
- 抽象处理负担不作为库存节点。

图用于检查循环和依赖，不代表运行时库存已经实现。

强连通分量使用物品对之间的候选边筛查潜在循环；是否能从外部起点真正启动，仍以上述 AND 超边可达性为准。

## 4. 循环与损耗

所有转化工艺必须具有正的有效人物时间区间。

当前 R1 中的制作—拆解强连通分量必须：

- 至少包含一个拆解工艺；
- 拆解目标声明 `target_consumed=true`；
- 按候选 `base_value × 数量` 计算的最大回收值严格小于目标候选价值；
- 不存在同一工艺把某个已消耗输入以相同物品、相同或更高最大数量返还的直接自增殖。

候选价值只是统一筛查代理。通过这些检查不证明质量、重量、能量或正式价格守恒。

## 5. 候选价值筛查

### 5.1 普通工艺

普通工艺的候选价值返回比：

```text
最大候选产出值
  = 主产出最大数量 × base_value
  + 库存副产物最大数量 × base_value

最大返回比
  = 最大候选产出值 / 已消耗直接输入候选值
```

以下只记为校准警告，不自动判为缺陷：

- 最大返回比 `< 0.25`；
- 最大返回比 `> 4.00`。

这两个阈值用于发现单位、数量或候选价值可能不一致的极端项，不代表合理利润率。

### 5.2 拆解与维修

- 拆解最大候选回收比 `>= 1.00` 为错误；
- 拆解最大候选回收比 `>= 0.75` 为警告；
- 维修已消耗材料值 / 目标候选价值 `>= 0.75` 为警告。

人工时间、设施折旧、品质、风险、来源和暴露均未折算为价格，因此比值只能用于筛查。

## 6. 共享瓶颈

审计报告以下集中度，但不自动判为错误：

- 同时被两张以上工艺使用、且服务两条以上资源主链的库存物品；
- 各设施能力覆盖的工艺数量；
- 各工具能力覆盖的工艺数量；
- 各最低岗位覆盖的工艺数量。

报告按使用工艺数、覆盖主链数和稳定 ID 排序。它用于未来挑选 Gate 子集，不解锁 Gate 2。

## 7. 严重度与通过标准

`ERROR`：

- Bundle 基线身份、R2-A 基线/Payload 或候选状态不一致；
- 工艺时间非正或区间倒置；
- 输入或产出候选价值无法计算；
- 上游来源断裂；
- 制造产出没有工艺用途、实际动作或流失路径；
- 拆解未消耗目标或最大候选回收比达到、超过 1；
- 转化循环没有有损拆解边界；
- 存在直接自增殖工艺；
- JSON 或 Markdown 无法逐字重建。

`WARNING`：

- 普通工艺候选价值返回比低于 0.25 或高于 4；
- 拆解候选回收比达到 0.75；
- 维修材料比达到 0.75。

R2-B 通过条件：

- `ERROR_COUNT=0`；
- 所有警告带有明确裁定；
- R2-A 语义审计与 R1 C1–C7 回归继续通过；
- JSON 与 Markdown 可逐字重建；
- 状态仍为 `candidate_only`，`runtime_authorization=NONE`。

## 9. 边界

- 不增加、删除、重命名或修改 R1 稳定 ID 与候选数值；
- 不把候选 `base_value` 当作售价、利润或正式经济；
- 不推导正式产能、技能阈值、设施吞吐或市场价格；
- 不允许整包运行时导入；
- 不改变 Gate 1A、Gate 1H 或 Gate 2；
- R2-B 通过只表示候选制造流更易筛选和校准。

C4 保留 C3 的 24 个非库存定义和 24 个转换流程，不新增存在形态或转换类型。

## 2. 边界

C4 只冻结候选物品、代表工艺、静态耐久职责和跨批接口，不冻结：

- 发电量、热值、过滤容量、电池容量、泵送速度或诊断精度；
- 设施耐久、压力、温度、化学浓度和实时供能网络；
- 自动燃料调度、管网、电网、维修队列或环境模拟；
- 正式货币、品质概率、技能经验曲线或运行时数值；
- 运行时导入器、UI、存档或 Gate 范围。

燃料、电池、过滤件和手泵只能提供候选能力入口。库存中有燃料或设备不等于聚落已经获得能源、净水或诊断效果。

## 4. C4 物品合同

所有 C4 物品继续遵守 V0.1 的库存字段合同。

### 4.1 批量物资

28 个 `bulk_material` 必须：

- 可堆叠；
- 以批次、污染、含水、来源或状态阻止错误合并；
- 有至少一个获得路径和一个消耗或流失路径；
- 不伪造独立实例耐久；
- 对燃料、化学品、粉尘、尖锐物或电池材料使用适当储存规则。

### 4.2 独立工具和电子设备

手摇泵与便携万用表是 `independent_item`，继续使用 V0.2 的 `durability_profile`：

- `tracked: true`；
- C4 不新增维修或拆解工艺时只能使用 `maintain_only` 与 `restricted`；
- 必须声明磨损来源和可见失效后果；
- 不冻结泵速、扬程、量程、误差或电池容量。

### 4.3 能源与处理边界

- 燃料的 `base_value` 不是热值；
- 电池模块库存不等于设备已供电；
- 滤芯库存不等于水已经净化；
- 过滤材料不能直接视为可饮用水；
- 万用表入库不自动发现故障；
- 手摇泵入库不自动连接水源。

## 5. C4 工艺合同

C4 工艺继续使用 C1 的制造字段，不增加新工艺类型。15 个工艺分布：

| 内容链 | 工艺数 |
|---|---:|
| 木材与固体燃料 | 4 |
| 液体燃料 | 1 |
| 有色金属 | 1 |
| 玻璃 | 1 |
| 砖灰砂浆 | 3 |
| 橡胶 | 1 |
| 过滤 | 3 |
| 电池 | 1 |
| **合计** | **15** |

约束：

- 所有工艺必须有非空输入和主产出；
- 副产物必须引用库存物品或受控负担；
- 多产出工艺不得把同一投入无损复制到多个输出；
- 燃料加工必须显式声明火灾、泄漏或化学暴露风险；
- 过滤件装配只生产组件，不直接生产洁净水；
- 电池模块装配只生产储能组件，不声明容量或供电时长；
- 工艺继续连接设施、工具、资格、人物有效时间和物流。

## 6. 接口覆盖层

`items.c4.yaml.interface_extensions` 可以向 C1–C3 的既有库存物品追加 C4 工艺引用。它：

- 只能引用 C4 工艺；
- 只能追加 `produced_by`、`used_by`、`repair_recipes` 或 `dismantle_recipes`；
- 不得覆盖、删除或重复前批接口；
- 不得向非库存定义追加制造接口；
- 合并后必须与工艺输入、产出和副产物精确双向一致。

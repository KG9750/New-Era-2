## 3. Codex 逐项裁定与修正

### 3.1 接受并修正：石灰石增加通风储存

**裁定：接受。**

`item.material.limestone` 同时具有 `dusty` 标签，描述与物流说明也明确粉尘风险。按照 C4 合同“对粉尘使用适当储存规则”的要求，在原有 `ambient`、`dry` 之外增加 `ventilated`，使静态储存元数据与物品语义一致。

修正后：

```yaml
storage_rule: [ambient, dry, ventilated]
```

### 3.2 驳回：空副产物数组属于缺陷

**裁定：驳回。**

合同允许工艺没有副产物，但要求 `byproducts` 字段显式存在。空数组准确表达“当前代表工艺不冻结库存副产物或受控负担”，比虚构副产物更符合候选数据边界。

### 3.3 驳回：粗制生物燃料必须使用液体体积单位

**裁定：驳回。**

该条目表示已经进入标准燃料罐的罐装燃料库存单位，不表示裸露液体体积。工艺已显式消耗一个 `sealed_fuel_canister`，因此 `piece` 与“一个封装燃料单元”的库存语义一致；C4 也明确不冻结热值和实时燃料网络。

### 3.4 驳回：玻璃碎料必须防震储存

**裁定：驳回。**

`glass_cullet` 是已破碎、待重新熔制的回收原料，不是完整玻璃片。其关键约束是干燥、上锁、防割和污染隔离；`reclaimed_glass_sheet` 已使用 `shock_protected`。给碎料增加防震规则会混同原料与成品职责。

### 3.5 驳回：政治资源链映射偏少属于缺陷

**裁定：驳回。**

C4 的主题是材料、能源、水处理和基础设施，主要服务工业、生存与安全链。政治链只在交易、稀缺材料或公共基础设施责任真实成立时出现；强行提高数量会把覆盖指标变成平均分配，并削弱用途映射的可信度。

### 3.6 驳回：简繁体不一致观察

**裁定：驳回。**

逐项核对后未发现会改变字段含义、ID、受控值或中文可读性的实际简繁体冲突。该观察没有给出可复现的文件位置或错误文本，不作为缺陷。

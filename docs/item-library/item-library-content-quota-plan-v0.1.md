## 1. 目的

本计划把 R1 的约 220 项内容规模拆成可验证增量，避免后续批次只按灵感追加，导致某些内容组过量而制造、医疗、装备或日常网络长期空缺。

“220 项”是候选覆盖目标，不是运行时承诺。非库存实体和权利记录继续计入目录定义，但不计入库存物品。

## 4. 计数映射

R1 内容组按一级分类汇总：

- 材料、能源与副产物：`material` + `byproduct_and_waste`；
- 零部件、工具与电子用具：`component` + `tool` + `electronic_device`；
- 食品、饮料、药品与医疗用品：`food_and_drink` + `medicine_and_medical_supply`；
- 书籍、数据载体、文件与凭证：`book_and_data` + `document_and_credential`；
- 家具、日用品、装饰与珠宝：`furniture` + `daily_supply` + `decoration_and_instrument` + `jewelry_and_valuable`；
- 其余内容组与同名一级分类一一对应。

报告必须同时显示一级分类和 R1 内容组配额，避免 18 个分类覆盖已经完成后失去后续数量约束。

## 5. 接受边界

达到 220 项只表示候选目录覆盖达到 R1 规划数量。任何条目进入运行时前，仍需按当前阶段重新验证用途、依赖系统、制造链、物流、价值、UI 和 Gate 授权。`R1_CANDIDATE_CONTENT_COMPLETE` 不等于运行时、平衡、UI 或玩家测试完成。

# Triage Labels

| Skill 中的角色 | GitHub 标签 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者或 Owner 补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由 AFK agent 独立领取 |
| `ready-for-human` | `ready-for-human` | 需要人类确认、参与或执行 |
| `wontfix` | `wontfix` | 已决定不处理 |

当 skill 要求应用某个 canonical role 时，使用上表对应的 GitHub 标签，不创建同义标签。
